## 常见问题

**在香港或澳门，还需要绕台湾 IP 吗？**

动画疯官网首页已经挂出公告：「因应动画疯港澳服务上线，服务条款已更新」，说明港澳地区已有正式服务入口。公告没有写明开放范围和片库是否与台湾一致，港澳读者可以先直接用本地网络打开看看，能播就不用买任何东西。

**动画疯本身免费，为什么还要花钱？**

平台是正版授权加广告的模式，非付费会员看完广告就能看当季新番，内容本身不收费。收费的是「你的 IP 不在允许范围内」这件事，跟平台定价无关。也正因为内容免费，任何一个付费方案都应该先算清楚自己一个月到底要看几部，再决定值不值。

**手机上能看吗，能投屏吗？**

iOS 通过 App Store 下载，Android 走 Google Play 或 APK，PC 端直接访问网页版，支持 AirPlay 与 Miracast 投屏。手机端走代理需要客户端支持全局或分应用代理，这一步比电脑上麻烦一些，买之前先确认你用的客户端能覆盖手机。

**买了但是播不了，从哪一步查起？**

按顺序看三件事：落地节点的 IP 是不是住宅或原生属性（机房段大概率过不了）；`ani.gamer.com.tw` 和 `api.gamer.com.tw` 有没有真的分流到台湾出口；大陆直连台湾的延迟是不是高到握手超时，如果是就补一个香港或日本的中转。这三步都排除之后仍然失败，才需要考虑换商家。
